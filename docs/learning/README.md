## 🧭 Why We Created This Guide

Building traditional web backends (CRUD, PostgreSQL, JWT Auth, File Uploads) is familiar territory. However, starting from **V2.5**, our system bridges deterministic backend engineering with modern AI agent architectures:

```text
Traditional Backend               AI & Knowledge Systems
───────────────────               ──────────────────────
PostgreSQL Tables        ──▶      Open Knowledge Framework (OKF)
REST Endpoints           ──▶      Intelligent Query Routers
Full-Text Search (ILike) ──▶      Hybrid RAG (BM25 + Dense + Cross-Encoders)
API Client SDKs          ──▶      Model Context Protocol (MCP) Server
Cron Jobs                ──▶      Life-Event State Machine
```

This guide explains **every concept from first principles**, why each exists, how the math/code works under the hood, and provides curated external resources so you can master each topic step by step.

```text
LLM interprets.
Database stores.
Rules engine decides.
OKF represents canonical knowledge.
RAG retrieves uncertain/unstructured knowledge.
Reranker prioritizes evidence.
Citations prove claims.
Human confirms personal information.
MCP exposes capabilities to agents.
```
