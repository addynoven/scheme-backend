# Ration Card

## 1. Purpose & Description
Family membership / BPL card

## 2. How to Obtain / Verification Guidelines
- Citizens can verify their Ration Card in the Document Vault using automated OCR fact extraction.
- Issued digitally via DigiLocker / State e-District Portal / Sub-Divisional Magistrate (SDM).
