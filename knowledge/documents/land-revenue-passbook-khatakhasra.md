# Land Revenue Passbook (Khata/Khasra)

## 1. Purpose & Description
Official Land Revenue Passbook (Khata/Khasra) for verification

## 2. How to Obtain / Verification Guidelines
- Citizens can verify their Land Revenue Passbook (Khata/Khasra) in the Document Vault using automated OCR fact extraction.
- Issued digitally via DigiLocker / State e-District Portal / Sub-Divisional Magistrate (SDM).
