# Land Possession Certificate

## 1. Purpose & Description
Khasra / Khatauni land record

## 2. How to Obtain / Verification Guidelines
- Citizens can verify their Land Possession Certificate in the Document Vault using automated OCR fact extraction.
- Issued digitally via DigiLocker / State e-District Portal / Sub-Divisional Magistrate (SDM).
